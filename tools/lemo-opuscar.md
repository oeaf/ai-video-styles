# lemo-opuscar

https://github.com/lemomo-ai/lemo-opuscar · 2894 star · MIT · 2026-09-26 创建（评估时 42 commits，维护活跃）

## 一句话

51 种影片风格的"样片库"：每种风格配一支完全用代码做出来的短片，选中风格、讲出故事，Claude Opus 5.5 当导演。

## 怎么玩

- 安装：`claude plugin marketplace add lemomo-ai/lemo-opuscar` / `claude plugin install lemo-opuscar@lemolab`
- 用法：直接说"用**水彩**风格做一条 45 秒短片，讲我家的咖啡农场"，agent 会先问一次关键问题（要不要先看分镜、有没有自己的配音/音乐素材），然后开工
- 每个风格有 `styles/<style>/STYLE.md`（长什么样、听什么样）+ 导演指南 `DIRECTOR.md` + 技术指南 `TECHNIQUE.md`
- 默认 1920×1080 / 24fps，一条片子约 30–60 分钟 agent 时间

## 风格覆盖（51 种，分类）

- 实证影像（新）：卫星影像、激光雷达扫描、公开城市数据、显微镜片——屏上每个数字都是实测或有出处的
- 手绘/绘画：蜡笔绘本、水彩、**中国水墨**、厚涂油画、单线条、白板解说、都市速写
- 东方传统：**皮影**、浮世绘、**红剪纸**、剪纸灯箱
- 版画：孔版印刷、半调、木刻、铜版蚀刻、丝网旅行海报
- 平面/字体：瑞士动态平面、60s 间谍片头、装饰艺术、蓝图、彩绘玻璃、象形图、ASCII 终端
- 信息/演讲：数据故事、等距信息图
- 卡通/动画、游戏、电影年代、材质/3D 等

## 适合谁

- 想做"电影感"短片但没学过动画的人：风格现成，讲故事就行
- 需要东方传统美学（水墨/皮影/剪纸）的中文内容创作者
- 数据新闻/科普：实证影像类风格直接拿真实数据拍

## 注意

- 风格是为 Opus 5.5 调的，换其他模型可能复现不了
- 需要 Node 20+、ffmpeg、Python 3.11+
