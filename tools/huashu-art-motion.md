# huashu-art-motion

https://github.com/alchaincyf/huashu-art-motion · 已收录并安装到本地 skill 库

## 一句话

35 种艺术风格代码绘制 + 9 种解说动画语法：把口播文案按参数渲染成动画片段，拼出整片。

## 怎么玩

- 本地 skill：`uv run --with playwright python scripts/engine/render.py`
- 35 种艺术风格用代码画出来并让画面动；9 种解说动画语法对应不同口播结构
- 可按口播参数渲染片段再拼接，适合长口播整片

## 实战背书

花叔用它做的一条视频，抖音 5 小时破 10 万播放——解说类内容的风格化有真实流量验证。

## 适合谁

- 知识解说/口播类视频：白板、Vox、3Blue1Brown 这类风格直接套
- 已有文案想快速视觉化的人

## 注意

- 人物素材仅 demo 授权，商用注意换素材
- Linux 下 macOS Vision 找词功能受限
